# Clip-Boy
An open-source DEF CON electronic badge — ESP32-S3, LVGL touch UI, digital-wasteland soul.

**Just want to flash one? No building required** — use the web flasher:
**https://flash.brycebadges.com** · Want a badge: https://brycebadges.com

**Build from source:** firmware is in [`Clip-Boy/`](Clip-Boy/) (Arduino sketch
`Clip-Boy.ino`) — see `Clip-Boy/scripts/build.sh`. Build-your-own hardware
(BOM, PCB Gerbers, enclosure, OmniTag) is under `Clip-Boy/hardware/`.

Docs & help: https://safehazard.github.io/Clip-Boy · License: **GPLv3** (`LICENSE`).
