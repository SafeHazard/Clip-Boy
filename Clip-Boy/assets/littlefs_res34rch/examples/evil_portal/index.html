Clip-Boy Evil Portal — EXAMPLE TEMPLATE

This is a demonstration page. It does not collect anything.

Captive portals are for authorized security testing and education only. You must have explicit written permission before running a portal that could capture another person's input on any network you do not own.

How to use this template

  1. Copy index.html and ap.config.txt from this folder to the root of the SD card.
  2. Edit ap.config.txt to the AP name you are authorized to use.
  3. Edit index.html to build your authorized test page.
  4. Run DATA > Tools > Evil Portal on the badge.

This template intentionally has no working capture form. To capture submitted input you must deliberately add a form that posts to /get — that is a conscious choice for an authorized engagement, not the default.
